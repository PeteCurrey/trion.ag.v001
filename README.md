# Trionn Website Duplicate

A pixel-accurate static duplicate of [trionn.com](https://trionn.com/), built with HTML5, CSS3, JavaScript, GSAP, and Lenis smooth scroll.

## Features

- **Preloader Animation**: 10 vertical belt strips, SVG logo drawing, slot machine 0-100 counter, and tagline reveals.
- **Mix-Blend-Mode Header**: Adaptive header navigation using `mix-blend-mode: difference` for high contrast against light and dark backgrounds.
- **Radial Clip-Path Menu**: Expanding circular drawer navigation on desktop.
- **Smooth Scrolling**: Integrated with Lenis.
- **Interactive 3D Cards**: Real-time cursor-tracking perspective tilt on Key Facts cards.
- **Interactive Contact Drawer**: Slide-out modal with custom service/budget selector dropdowns.
- **Local Assets**: All SVG icons, partner logos, and responsive MP4 video backgrounds included.

## Running Locally

Open `index.html` directly in any modern browser, or start a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
